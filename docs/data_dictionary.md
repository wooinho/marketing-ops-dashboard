## 2. 테이블 정의

### revenue_target_actual_monthly.csv → `revenue_monthly`
그룹(전체/1그룹/2그룹) × 월(1~12) 단위 매출/매입/매출이익 목표·실적.

| 컬럼 | 설명 |
|---|---|
| group → grp | `전체` \| `1그룹` \| `2그룹` |
| month | 1~12 |
| revenue_target / cost_target / profit_target | 해당 월의 목표(연간 목표를 월별로 배분한 값) |
| revenue_actual / cost_actual / profit_actual | 해당 월의 실적(스냅샷 B). 그룹의 실적 반영 기간을 넘는 월은 `NULL` |
| has_actual | 1=실적 반영, 0=목표만 존재 |

**실적 반영 기간**: 1그룹 1~11월, 2그룹 1~10월. 이 범위를 벗어나는 달은 원본 시트에 매출/매입이
0으로 표시되어 있어도(그리고 일부 달은 매출이익 셀에 30,000,000~100,000,000원 등 **평탄한(flat) 값이
남아있어도**) 실적이 아니라 목표/추정치 잔여값으로 판단해 `NULL`로 처리했습니다.
(자세한 근거는 4번 항목 "매출이익 플랫값" 참고)

### revenue_group_annual.csv → `revenue_group_annual`
그룹 단위 연간 목표/실적/달성률(스냅샷 B의 `26' 목표` / `26' Total` / `달성율` 컬럼).
`cost_rate_pct`는 원본 시트에 매입 달성률이 정의되어 있지 않아 항상 `NULL`입니다(매입은 적을수록 좋으므로 달성률 개념이 없음).

### revenue_client_annual.csv → `revenue_client_annual`
광고주별 연간 목표/실적/달성률(스냅샷 B). `client_raw`는 원본 표기, `client`는 정규화된 명칭
(`config/client_name_mapping.csv` 참고). `quality_flag` 값:

- `REF_ERROR` — 목표 셀이 `#REF!`(참조 깨짐). 광고주 "타이거"만 해당.
- `DIV0_NO_TARGET` — 목표가 비어 있어 달성률이 `#DIV/0!`. "신규 광고주" 슬롯들(목표 미확정, 실적도 0).
- `TARGET_ONLY_NO_ACTUAL` — 목표는 있으나 실적이 아직 0(스나이델뷰티).

### revenue_client_monthly.csv → `revenue_client_monthly`
광고주별 월간 매출/매입/매출이익(스냅샷 B). 1그룹은 1~11월, 2그룹은 1~10월만 값이 있습니다
(그 외 월은 로드 시점에 CSV 자체에 행이 없음 = 해당 안 됨).

### resource_mm_group1.csv / resource_mm_group2.csv
1·2그룹 리소스 현황 시트의 "그룹합계"(1그룹) / "브랜드별 합계"(2그룹) 행을 월별로 그대로 옮긴 표입니다.
파생 계산 없이 원본 값을 그대로 실었으며, `note` 컬럼에 해당 셀의 특이사항을 기록했습니다.

### staff_mm_group1.csv / staff_mm_group2.csv
담당자별 월간 MM 투입(근사치 포함). `basis` 컬럼이 `원본 월간값`이면 시트에 월 단위로 이미 집계된

- "젤라또 피케"(공백 포함 원본) → `젤라또피케`(공백 제거, 리소스 시트 표기와 통일).

  `Qeelin`과 정확히 일치(예: 7월 599,895원)하여 **동일 광고주의 내부 별칭(코드명)** 으로 판단해 매핑했습니다.
  (판단 근거: 우연히 여러 달에 걸쳐 두 자릿수까지 일치하는 숫자가 반복되는 것은 별칭일 가능성이 매핑 오류일

- 2그룹 리소스 시트의 퓨리나 5개 서브라인(프로플랜/ONE/프리스키/자사몰/SNS)은 매출 트래킹 시트에서는

  서브라인 구분을 유지했습니다.

## 4. 데이터 품질 이슈 전체 목록

1. **스냅샷 A vs B** — 위 1번 항목. B를 정본으로 사용.
2. **`#DIV/0!`** (원본에 약 238회 등장) — 매출이 0인 매입 전용 행 등에서 발생. 오류가 아니라 "계산 불가"로
   간주해 `NULL`(대시보드에는 N/A)로 처리했습니다.
3. **`#REF!`** — 광고주 "타이거"의 매입/매출이익 **목표** 셀에서만 발생(참조가 깨진 셀). 목표를 `NULL`
   처리했고 실적도 0으로 기록되어 있어 `REF_ERROR` 플래그를 달았습니다. (구버전 목표관리 표에서도
   동일 오류가 나타나지만 그 표는 애초에 사용하지 않습니다.)
4. **음수 표기 두 가지** — `-₩1,234`와 `(1,234)` 형태가 모두 등장. `src/ingestion.clean_currency()`가 둘
   다 음수로 정상 변환합니다.
5. **통화 문자열 형태 혼재** — `"₩84,563,690"`처럼 원화 기호+쉼표가 붙은 문자열과 `84563690`처럼 순수
   숫자가 같은 표 안에 혼재. `clean_currency()`가 `₩`/쉼표/공백을 제거한 뒤 숫자로 변환합니다.
6. **매출이익 "플랫(flat)" 값** — 여러 광고주(예: 한화생명 8~12월, 풀무원요거트그릭 8~12월 등)의
   매출이익 컬럼이 특정 시점 이후 매달 정확히 같은 금액(예: 30,000,000원, 8,000,000원)으로 반복됩니다.
   매출/매입은 그 달 실제 값이 들어있는데 매출이익만 평탄한 것으로 보아, **원본 시트의 매출이익 수식이
   그 시점 이후 갱신되지 않고 이전 추정치가 복사되어 남아있는 것으로 추정**합니다. 그룹의 실적 반영
   기간(1그룹 11월까지/2그룹 10월까지) 안쪽 달은 원본 값을 그대로 실었고, 범위를 벗어난 달은 `NULL`
   처리했습니다. 정확한 매출이익 재계산은 원본 시트 소유자 확인이 필요합니다.
7. **✅ 해결됨 (2026-09-29 갱신) — 2그룹 8월 리소스 그룹합계 공백** — `1그룹 프로젝트 리소스 현황`과 달리
   `2그룹 프로젝트 리소스 현황`의 8월 섹션은 매출/매입/수익/생산성 총계 셀이 원본에서 비어 있고, MM
   투입량만 브랜드별로 기록되어 있었습니다. **이번 갱신에서 원본 시트가 수정되어 퓨리나/풀무원요거트/
   매일유업/CJ문화재단/Ayrow는 매출·매입·수익이 모두 채워졌습니다.** 다만 8월에 신규 등장한 "PT" 컬럼만은
   여전히 매출/매입/수익/MM이 전부 공백입니다(항목 19 참고).
